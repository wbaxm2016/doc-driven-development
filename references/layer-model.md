# 分层模型：一份事实只住一层

## 判定问句（先问，再选层）

| 层 | 目录（默认） | `layer` 值 | 它回答的问题 | 典型放错 |
|---|---|---|---|---|
| 门面 | `00-门面/` | `facade` | 这是什么、现在做到哪、**下一步做什么** | 把方案写进门面（方案属决策） |
| 架构 | `10-架构/` | `architecture` | 系统怎么搭、机制为何这样 | 把"必须成立的条款"写在架构里（应进契约） |
| 契约 | `20-契约/` | `contract` | 哪条**必须**成立、怎么验收 | 写成解释文（无「必须/不得」，E13 会拦） |
| 决策 | `30-决策/` | `decision` | 选了什么、**还摆着哪些选项**、何时推翻 | 把结论当记录，删掉被否决的选项 |
| 运行 | `40-运行/` | `operation` | 怎么跑、参数、实测、快照 | 把排期写进运行 |
| 术语 | `50-术语/` | `glossary` | 规范名叫什么、禁用什么别名 | 在术语表里写完整定义（应只索引） |
| 规范 | `60-规范/` | `norm` | 人怎么协作、文档怎么组织 | 把业务规则塞进规范 |
| 过程 | `70-过程/` | `process` | 怎么一步步变成现在这样 | 把过程当裁决依据（`authority` 必须 4） |

## 元数据语义（写错比写多更坏）

| 字段 | 允许值 | 关键约束 |
|---|---|---|
| `status` | `active` / `proposed` / `draft` / `implemented` / `superseded` / `snapshot` / `reference` | `active` 表示**现在照它做**；`snapshot` 是历史留档、**不得当现状引用**；`reference` 是被引用但不排期 |
| `authority` | `1` 最高 … `4` 最低 | 冲突仲裁按数字小者胜。**过程档案固定 4**，永不参与裁决 |
| `updated` | `YYYY-MM-DD` | 不得晚于今天；**失真比错误更危险**——它决定别人判断"哪份最新" |
| `summary` | ≤ 80 字 | 会被索引直接展示，超长报 E5 |

## 层定义只有一个来源：`docs/_schema.json`

```json
{
  "layers": { "00-门面": "facade", "20-契约": "contract", "30-决策": "decision",
              "40-运行": "operation", "70-过程": "process" }
}
```

- **加层**：建目录 + 在这个文件里加一行。三份脚本都读它，不用改代码。
- **改目录名**：改 key（`"20-条款": "contract"`），脚本跟着走——包括 ADR 目录、收件箱、时间线、计划文档的位置，都是从层值推导的。
- **删层**：删目录 + 删这一行。留着空目录会报 E9。
- 旧项目若已有 `docs/_layers.json`，脚本会兼容读取；但**不要再新建**，只认 `_schema.json`。

同一个文件里还写着 `status` / `authority` / `domain` 枚举、七段与六段结构、编号规则、文件名——**任何"结构"都只在这一处定义**。

## 唯一事实源怎么保证

1. 在 `docs/README.md §1` 写一张 **「想知道 → 读哪份 → 唯一」** 表：一件事只有一行。
2. 出现第二份定义同类内容时，**不要两边同步维护**：把弱的那份降级为 `reference`（保留历史）或直接删掉，只留一行指针。
3. `authority` 只给真正的权威：两份同为 2 的"排程"文档＝已经坏掉了。
4. 机器只能查**形式**（字段、链接、重复 summary、术语旧称）；"两份在说同一件事"必须靠这张表人工守。所以表要短——超过 10 行说明职责还没收敛。

## 最小可行子集

新项目不必一次上 8 层。`doc_init.py` 默认就只建 5 层：`门面 + 契约 + 决策 + 运行 + 过程`。`--full` 再加 架构/术语/规范。

术语层建议早加：E16 依赖 `50-术语/别名表.md` 才能工作；没有它，术语检查静默跳过（不算错，但也就没有保护）。

## 单向依赖（防止层级互相污染）

```
过程层（只记录） → 不做约束
决策层（选项与结论） → 产出契约条款
契约层（必须成立） → 被架构/运行实现
门面层（指向） → 只引用，不复写
```

反例（真实踩过，不是假设）：

- 把方案写进门面 → 半年后方案变了，没人知道门面该不该改。
- 把排期写进决策 → 两个地方都在说"先做什么"，此后以哪个为准全凭记忆。
- 用 `authority: 4` 的会话档案去否掉 ADR → 记录变成了裁决依据，整个权威体系失效。
