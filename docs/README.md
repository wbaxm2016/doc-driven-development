## 4. 目录树

默认铺 5 层；带 `--full` 时再加 3 层。**层的唯一来源是 `docs/_schema.json`**，本树只是给人看的快照——加层就同步改这里一行，不要改脚本。

```
docs/
├── 00-门面/     # 定位、计划                （默认建）
├── 20-契约/     # 必须成立的条款            （默认建）
│   └── _delta/  # 契约增量：只写改哪几行     （W1.1）
├── 30-决策/     # ADR：一文件一决策         （默认建）
├── 40-运行/     # 怎么跑、参数、实测        （默认建）
├── 70-过程/     # 会话档案、收件箱、时间线  （默认建，不参与裁决）
├── 10-架构/     # 系统怎么搭                （--full）
├── 50-术语/     # 规范名与别名表            （--full）
└── 60-规范/     # 协作与文档规范            （--full）
```
