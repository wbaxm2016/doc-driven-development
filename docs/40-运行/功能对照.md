# 功能对照清单

> 用法：实施完成后填一次，每行一条功能；取数是 `python scripts/devlog.py features --state 实施中`。
> 结论只写三种：`一致` / `差异` / `未覆盖`；写「差异」「未覆盖」时必须**同时登记一条 ISS**——只写在清单里等于没记。
> 对照看三件事：**入口在不在**（`E24`）、**有没有行**（`W9`，只提醒不判内容）、**行为覆盖不覆盖验收口径**（只能人读）。
> 四列固定：功能 / 该验什么 / 结论 / 差异 · 证据——`SKILL.md` 主干道第 8 格说的是同一件事。
> 2026-11-04 起：`doc_check` 对 F-021+ 的已验收功能做 W 级「有行」提醒（`W9`）；有行 ≠ 对照过，结论仍人读。

**存量口径**（ISS-063）：本清单自 2026-11-03 起承接。F-001–F-020 的对照发生在 2026-10-31 – 11-02 各场会话的 §3.4 与任务考核里，**不回填**——回填只能靠今天重读一遍，那是「现在的观测」，不是当时的对照，写进来是伪证据。存量功能只由 `E24` 保证「入口存在」；要重判某条，补一行新观测并写明日期。
