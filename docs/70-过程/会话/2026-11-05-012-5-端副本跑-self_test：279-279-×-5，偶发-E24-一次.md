## 3. AI 侧记录

### 3.1 需求理解

ISS-085 其实有两半：①装进去的文件在本机 Python 下能不能跑；②宿主会不会调用它们。①能在 CLI 里测，②不能。本轮只做①，并把 ISS-085 收窄到②，不假装已经解决。

### 3.2 实现思路

1. 对 5 个安装目录逐个跑 `<端>/skills/doc-driven-development/scripts/self_test.py`。
2. 记录通过数：**5 端各 279/279**，与仓库的 281/281 差 2 条。
3. 查差异来源：逐条比对 PASS 行，少的两条是「装机后逐字节核对 缺 0 / 不等 0」与「历史残留被报出并清掉（ISS-039）」——都依赖仓库目录（`dist/` 与安装记录），副本里按设计跳过。
4. 串跑时 qoder 端一次报 `E24`「状态词不在白名单」失败；单跑同端 **279/279 全过**，不复现 → 登记 ISS-087（偶发）。
