## 3. AI 侧记录

### 3.1 需求理解

ISS-084 问的是「数据层的替换成本」。可测法只有一种：**换掉取数实现、保持行为逐字节一致**——一致就说明取数层与渲染、断言解耦；不一致就说明耦合到别处，那本身也是数据。所以选 `load_directions()`：它被 `plan.py check` 与 `tree` 共用，换它最能暴露「一改就牵动别处」。

### 3.2 实现思路

1. 取基线：`plan.py tree` 全文 sha256 `B71753B7…`，`plan.py check` errors=0；调用点两处（L963 / L1150）。
2. 换实现：原版先 `heads.index` 再循环取列；新版先建 `idx = {列名: 下标}`，再按 `idx` 取——语义相同，写法不同。
3. 比对：`tree` 输出 sha256 与基线**完全一致**；`plan.py check` 0 error；`self_test` **281/281**，**0 条断言改动**。
4. 成本：**1 个文件，+7 / −6 行**；调用点 0 处改动。
5. 还原：`git checkout -- scripts/plan.py`，再跑 `tree` 与基线比对，仍一致。
