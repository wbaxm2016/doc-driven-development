# 问题收件箱

> **规则**：开发过程中发现的问题（缺陷 / 口径冲突 / 文档债 / 风险 / 待决 / 机会）**当场登记一行并继续当前话题**。用户不必在对话中回应——这是"关掉会话无负担"的前提。
> **编号**：`ISS-nnn`，只增不复用；`deferred` 必须有「回到条件」。
> **不是待办清单**：排序由 [00-门面/开发计划.md](../00-门面/开发计划.md) 决定，本表只保证"不会被忘掉"。
> **写法**：一行一个问题；「影响」必须具体到"不处理会怎样"，不写"影响较大"。
