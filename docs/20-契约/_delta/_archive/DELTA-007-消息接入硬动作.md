# DELTA-007 · 消息接入硬动作

> 依据：用户 2026-11-11 拍板（009 档复述门过）——部分 agent 对技能遵守度差，原因之一是没有根据用户消息找到对应的流程入口；接入动作从「提示」升为「硬动作」，仍不新增脚本判据、不构成跳过门禁的理由。
>
> 合并守则：本篇已合并归档，**不得**再改动已合并的逐字变更；后续要再升级 REQ-054，开新 delta，不动本快照（`_delta/README.md` §7）。
