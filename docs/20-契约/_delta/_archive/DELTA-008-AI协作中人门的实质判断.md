## 2. 逐字变更

**变更 1 · MODIFIED · REQ-058**

合并前（原行）：

```markdown
| **REQ-058** | WHEN 一次改动的档位（小 / 中 / 大）被判定后 THE SYSTEM SHALL 只要求该档在分工边界表里列明的人门，其余门合并为前后各一次回顾；方向、契约口径、发版与回滚、开放问题收口在任何档位都要过人，档位只决定门的密度与时机 | 按小 / 中 / 大各走一场：小档不建档、只跑触及校验；中档前置 / 后置各一次回顾；大档五道门齐全；不可逆门不降；`self_test` 全绿、五连跑 0 error；人读「一次回顾」未被橡皮章 | `python -c "import pathlib,sys;p=pathlib.Path('SKILL.md');sys.exit(0 if '档位：人门按代价伸缩' in p.read_text(encoding='utf-8') else 1)"` | 已实现 | 用户 2026-11-12「先做B」「第一种」「1. 认 2. 增加分工挡位，做错了只是推翻重写规则。」、ISS-108、D20、W35.1、K48 | 复述✓ 2026-11-12｜2026-11-12-007 §4 D1 |
```

合并后（现目标中的行）：

```markdown
| **REQ-058** | WHEN 一次改动被判定档位（小 / 中 / 大）THE SYSTEM SHALL 把对齐、评审、设计、对照、考核当作必须覆盖的检查维度，而不是五次必须停下等人批准的门：可逆且不改变已确认目标与约束的实现，AI SHALL 按项目约定采用可回退默认直接推进并自查，不逐项请求批准；只有当缺失的人的判断会改变目标 / 验收、触及数据写入 / 保留 / 删除、权限 / 安全 / 外部承诺，或令工作无法运行 / 验证时，AI SHALL 只问最小必要的问题，或不执行该高影响外部动作并说明影响与缺口；需要人判断时，AI SHALL 提供足以判断的结果——按情境提供可用成果或可观察证据，两者择一即可；人的参与 SHALL 用于目标、价值取舍、风险边界或结果判断 | 文档不再要求逐项批准；可逆事项不停等确认；高影响动作只在授权范围内执行；人读 SKILL 分工边界与主干道 | `python -c "import pathlib,sys;s=pathlib.Path('SKILL.md').read_text(encoding='utf-8');sys.exit(0 if '人的参与要改变判断结果' in s and '可用成果或可观察证据' in s else 1)"` | 已实现 | 用户 2026-11-12 对档位的确认；用户 2026-11-14「这个哲学没问题，调整技能符合该哲学，并且将该哲学记录到README与vision中」、D20、W20.2、K51 | 采纳✓ 2026-11-14｜本会话 §2 #4 |
```
