# 别名表

> **唯一来源**：`scripts/doc_check.py` 的 E16 只读本表。想让某个旧称失效，删掉对应行即可。
> 扫描范围：门面 / 契约 / 规范 三层，且 `status` 不是 snapshot / reference 的文档。
> 豁免写法：同一行里出现「旧称」「曾称」「别名」「原名」「禁止写法」的句子不报（登记性描述）。

## 2. 使用约定

1. 只登记**会混淆**的别名，不要把所有同义词都塞进来——表越长越没人看。
2. 规范名一旦确定，ADR 与历史快照**不改写**（它们记录的是当时口径），只约束新的对外表述。
