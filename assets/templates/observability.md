# 可观测性地图

> 一份地图回答两件事：每个组件怎么工作、串联时哪一步断了。
> **四维是验收框架**：可观测 / 可解释 / 可诊断 / 可改进；**四问是记录内容**：运行的是什么 / 为什么是这个结果 / 预期是什么样的 / 系统下一步是什么。
> 技能只提供模板 / 检查 / 参考实现；项目运行时按本图自行实现，不替项目跑运行时。
